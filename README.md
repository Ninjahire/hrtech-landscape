# HRTech Landscape 🗺️

> A comprehensive, community-maintained taxonomy of the Human Resources Technology market — covering every category, subcategory, and key vendor across the full HR lifecycle.

**Maintained by [NinjaHire](https://ninjahire.co).** Last updated: June 2026.

Think of this as the open-source version of the famous MarTech landscape — but for HR technology. Use it to understand the market, evaluate vendors, or identify gaps.

## How to Use This

- **Buyers** — Use the taxonomy to map your current HR tech stack and identify gaps

## Category Consolidation Trends

The HRTech market is consolidating around platform plays:

1. **HRIS expanding into ATS** — Workday, Rippling, BambooHR all now include recruiting
2. **ATS expanding into sourcing** — Greenhouse, Lever adding sourcing modules
3. **AI-first platforms** — Purpose-built AI platforms replacing point solutions
4. **Staffing-specific stacks** — Bullhorn, Vincere, NinjaHire building vertically integrated tools for staffing firms
